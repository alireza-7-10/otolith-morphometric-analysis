# Otolith Morphometric Analysis

## Comparative Descriptive Morphology of Sagittal Otoliths in Three *Epinephelus* Species

### 📌 Overview

This project presents a morphometric analysis of sagittal otoliths from three
*Epinephelus* species collected from the Persian Gulf and Gulf of Oman.

The study focuses on identifying morphological differences among species using
digital image analysis and quantitative morphometric measurements.

### 🐟 Study Species

- *Epinephelus areolatus*
- *Epinephelus coioides*
- *Epinephelus stoliczkae*

### 🔬 Research Methods

The analysis includes:

- Collection and examination of right sagittal otoliths
- Digital imaging of otoliths
- Image processing and measurement using ImageJ
- Quantitative morphometric analysis
- Comparison of morphological characteristics among species

### 📏 Morphometric Measurements

The following measurements are obtained from otolith images:

- Otolith Length (OL)
- Otolith Width (WO)
- Rostrum Length (RL)
- Perimeter
- Area
- Sulcus Area

### 📊 Morphometric Indices

Several size-independent ratios are calculated:

**Width-to-Length Ratio**

`E = WO / OL`

**Rostrum-to-Length Ratio**

`R = RL / OL`

**Sulcus Area Ratio**

`S = Sulcus Area / Total Otolith Area`
