# Data Description

## `otolith_descriptive_indices.csv`
This file contains morphometric indices calculated from right sagittal otoliths of three *Epinephelus* species.

| Column | Description | Formula |
|--------|-------------|---------|
| `Species` | Species name | - |
| `Sample_Order` | Sample ID | - |
| `E_WO_OL` | Width-to-Length Ratio | WO / OL |
| `R_RostrumLength_OL` | Rostrum-to-Length Ratio | RL / OL |
| `S_SulcusArea_TotalArea` | Sulcus Area Ratio | Sulcus Area / Total Area |
